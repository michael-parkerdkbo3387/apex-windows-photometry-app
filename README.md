## Overview

APEX provides a Windows-based environment for reducing and examining astronomy data. Its workflow is organized around FITS images, detected sources, and photometric measurements, allowing users to progress from raw observations to calibrated results through either a guided GUI or command-line processing.

The application combines several common observational astronomy tasks in one desktop tool. These include plate solving, catalog construction, light-curve creation, and period-search techniques, making APEX suitable for imaging sessions, time-series observations, and subsequent analysis without requiring a separate application for each stage.

---

## What APEX Provides

- Step-by-step FITS photometry through a guided workflow
- Detection of sources and creation of master catalogs
- WCS registration through internal or external solving tools
- Forced-aperture measurements with optional PSF photometry
- CMD calibration and isochrone-fitting capabilities
- Light-curve creation, detrending, and combination of multiple nights
- Variability searches using Lomb-Scargle, PDM, and BLS
- Both graphical and command-line operation

## Typical Workflow

A standard APEX session can follow these stages:

1. Add the FITS image set to the project.
2. Locate sources and create a master catalog.
3. Apply WCS alignment when plate solving is required.
4. Choose aperture photometry or PSF photometry.
5. Produce light curves, detrend them, or combine observations from several nights.
6. Run the available period-analysis methods to investigate variability.
7. Inspect or export the resulting catalogs, curves, and fit data.

### CLI-Oriented Use

A command-line run generally involves:

- Launching the analysis mode
- Providing the directory containing the FITS data
- Choosing the required photometry and period-analysis operations
- Checking the generated catalogs, light curves, and fit outputs

When working through the GUI, open APEX and proceed through the workflow panels shown in the application.

## Frequently Asked Questions

**How can I obtain a newer version?**  
Use the current release or build link provided in this repository to find the latest version files.

**Is command-line processing available?**  
Yes. APEX can be used through either its GUI or CLI mode.

**Where does APEX write its results?**  
The application saves outputs to the project or output locations selected during configuration.

**What should I do if WCS alignment fails?**  
Try the other available solver, and confirm that the input images and coordinate information are correct.

**Can observations from different nights be analyzed together?**  
Yes. APEX can detrend light curves and merge them across multiple nights for longer time-series studies.
